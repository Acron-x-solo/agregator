# Claude Aggregator

Локальный агрегатор API-ключей для Claude Code. Claude Code смотрит на `http://127.0.0.1:8787`, а агрегатор сам ходит к провайдерам (JustWoker, TabiToken и любые другие Anthropic-совместимые релеи) и **автоматически переключается на следующий ключ, если текущий исчерпался, упёрся в лимит или недоступен**. Свап/добавление/удаление ключей — через веб-админку, без перезапуска.

Плюс **пульт**: тот же процесс поднимает отдельную панель на `127.0.0.1:8788`, из которой можно запускать Claude Code в любой папке, видеть вызовы инструментов и ответ в реальном времени, и рулить тем же самым из Telegram. Панель публикуется наружу через Cloudflare Tunnel — прокси `/v1` и админка ключей при этом остаются только на локалхосте.

## Запуск

Нужен только Node.js (16+).

```
start.bat
```
или
```
node server.js
```

Админка открывается здесь: **http://127.0.0.1:8787/**

## Настройка Claude Code (один раз)

В `%USERPROFILE%\.claude.json` (или `~/.claude/settings.json`) в блок `"env"`:

```json
"env": {
  "ANTHROPIC_API_KEY": "aggregator",
  "ANTHROPIC_BASE_URL": "http://127.0.0.1:8787",
  "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
}
```

Ключ здесь — заглушка, реальный ключ подставит агрегатор. После этого Claude Code перезапустить один раз — дальше все манипуляции с ключами идут через админку без рестартов.

## Как работает фейловер

- **402 / «нет средств / credit / balance / quota»** → провайдер помечается «Исчерпан» и исключается из ротации, запрос автоматически уходит следующему.
- **429** → cooldown на настраиваемое время (по умолчанию 60 сек), потом снова в ротации.
- **Сетевые ошибки / 5xx / таймауты** → короткий cooldown (30 сек) и переход к следующему.
- **401/403** → «Ошибка ключа», исключается до ручного сброса.
- Если релей возвращает ошибку с кодом 200 внутри JSON — она тоже распознаётся и срабатывает фейловер.
- Стратегии ротации: `priority` (по порядку списка), `round_robin` (равномерно), `pin` (закреплённый первым).
- Кнопка «Тест» в админке шлёт минимальный запрос (`max_tokens: 1`) и проверяет живость ключа.

## Пульт: Claude Code из браузера и из Telegram

Пульт поднимается тем же `node server.js` на **отдельном порту 8788** и живёт независимо от прокси ключей. Он запускает настоящий `claude` в headless-режиме (`--output-format stream-json`), по одному процессу на ход, и стримит наружу всё, что тот пишет: текст по мере генерации, вызовы инструментов, результаты, стоимость хода.

Ссылка на вход печатается в консоль при старте и всегда доступна в админке на вкладке **«Пульт»**:

```
http://127.0.0.1:8788/?t=<control.token>
```

Токен генерируется сам при первом запуске (24+ символа) и лежит в `config.json` → `control.token`. Открыть панель без него нельзя: `?t=…` ставит HttpOnly-cookie, дальше токен в адресе не нужен. Восемь неудачных попыток с одного IP → блокировка на 5 минут.

### Что умеет панель

- Список сессий: папка, модель, режим прав, число ходов, потраченные деньги, статус (ждёт / думает / ошибка).
- Чат с живым выводом: реплики, вызовы инструментов и их результаты — отдельными плашками, текст доливается по мере генерации.
- Создание сессии со встроенным файловым браузером для выбора папки, смена модели/режима/усилия на ходу, «Стоп» (убивает процесс вместе с детьми), очистка истории, удаление.
- Настройки: дефолты новых сессий, путь к `claude`, таймаут хода, управление Cloudflare-туннелем и Telegram-ботом, состояние ключей агрегатора.
- Вёрстка мобильная: на узком экране список сессий уезжает в выдвижную панель.

### Telegram

1. Взять токен у [@BotFather](https://t.me/BotFather).
2. Вставить его в панели (Настройки → Telegram) или руками в `config.json` → `control.telegram.botToken`, затем «Запустить».
3. Написать боту `/auth <код привязки>`. Код показан в админке и в настройках панели; вместо него подойдёт и полный токен панели.

Чат после авторизации попадает в белый список (`control.telegram.allowedChatIds`), любые другие чаты бот игнорирует. Дальше можно просто писать текст — он уйдёт в привязанную к чату сессию, а бот будет править одно сообщение по ходу работы (не чаще раза в 2.5 сек), пока не дойдёт до итога вида `✅ 3 инстр. · 41 с · $0.12`.

Если `api.telegram.org` из твоей сети недоступен (бот падает с «таймаут запроса к Telegram»), впиши прокси в поле «Прокси для api.telegram.org» или в `control.telegram.proxy`:

```
http://127.0.0.1:10809      обычный http-прокси (метод CONNECT)
socks5://127.0.0.1:10808    socks5, при необходимости socks5://user:pass@host:port
```

Прокси используется только для Telegram — запросы к провайдерам ключей и к Cloudflare идут как раньше.

Команды: `/new [название]`, `/sessions`, `/use <id>`, `/cd <путь>`, `/ls`, `/model <модель>`, `/mode <режим>`, `/effort <уровень>`, `/stop`, `/clear`, `/status`, `/cost`, `/del`, `/id`, `/panel`, `/p <текст>`, `/help`.

Режимы прав — только эти: `acceptEdits`, `auto`, `bypassPermissions`, `manual`, `dontAsk`, `plan`. Усилие: пусто, `low`, `medium`, `high`, `xhigh`, `max`.

### Cloudflare Tunnel

Наружу отдаётся **только пульт**. Нужен `cloudflared` (ставится инсталлятором Cloudflare, по умолчанию ищется в `C:\Program Files (x86)\cloudflared\cloudflared.exe`).

- **`quick`** — без регистрации: агрегатор сам поднимает `cloudflared tunnel --url http://127.0.0.1:8788` и вытаскивает выданный адрес `https://…trycloudflare.com` из его лога. Адрес меняется при каждом перезапуске, годится «прямо сейчас».
- **`token`** — постоянный домен: создать туннель в панели Cloudflare Zero Trust, скопировать его токен в `control.cloudflare.tunnelToken`, указать `hostname`. Запускается как `cloudflared tunnel run --token …`.

Кнопки «Запустить / Перезапустить / Остановить» есть и в админке (вкладка «Пульт»), и в самой панели. Готовая ссылка с токеном показывается там же — её и надо открывать с телефона.

## Конфиг

Всё лежит в `config.json` рядом со скриптом. Можно править руками — файл подхватывается на лету без рестарта:

```json
{
  "port": 8787,
  "host": "127.0.0.1",
  "strategy": "priority",
  "cooldownMs": 60000,
  "downCooldownMs": 30000,
  "activeId": null,
  "providers": [
    {
      "id": "...",
      "name": "JustWoker",
      "baseUrl": "https://api.justwoker.icu",
      "apiKey": "sk-...",
      "enabled": true
    }
  ],
  "control": {
    "enabled": true,
    "port": 8788,
    "host": "127.0.0.1",
    "token": "<генерируется сам>",
    "cookieSalt": "<генерируется сам>",
    "claudeBin": "claude",
    "defaultCwd": "",
    "defaultModel": "",
    "permissionMode": "acceptEdits",
    "defaultEffort": "",
    "stream": true,
    "turnTimeoutMs": 1800000,
    "extraArgs": [],
    "env": {},
    "telegram": {
      "enabled": false,
      "botToken": "",
      "pairingCode": "<генерируется сам>",
      "proxy": "",
      "allowedChatIds": [],
      "bindings": {}
    },
    "cloudflare": {
      "enabled": false,
      "mode": "quick",
      "tunnelToken": "",
      "hostname": "",
      "cloudflaredPath": "cloudflared",
      "autoRestart": true,
      "autoStart": true
    }
  }
}
```

Блок `control` дописывается сам при первом запуске — вместе с токеном панели, солью для cookie и кодом привязки для Telegram. `token`, `cookieSalt`, `tunnelToken` и `botToken` — секреты, `config.json` наружу не отдаётся ни одним эндпоинтом.

## Что где слушает

| Порт | Что | Доступ |
| --- | --- | --- |
| 8787 | прокси `/v1` + админка ключей | только `127.0.0.1` |
| 8788 | пульт (веб-панель) | `127.0.0.1` + Cloudflare-туннель, если включён |

Прокси и админка ключей наружу не торчат никогда. Через туннель уходит только пульт, и то за токеном — но помни, что ссылка вида `…/?t=<токен>` этот токен содержит, так что делиться ей не стоит. Если токен утёк — сотри `control.token` в `config.json` и перезапусти: сгенерируется новый (старые cookie при этом тоже станут недействительны).
